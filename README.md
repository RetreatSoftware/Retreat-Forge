# Retreat-Forge

A game creation tool for developers.

1. **Select** modular game features through an interface (checkboxes).
2. **Build** — the selected features are resolved and automatically assembled into a playable game template (not an empty skeleton).
3. **Customize** the generated project with AI assistance, adapting mechanics, rules, and content. The code stays fully accessible and editable.

If a combination of features is incompatible, Forge explains why instead of producing a broken project.

## Part of the Retreat ecosystem

- [Retreat-CoreSDK](https://github.com/RetreatSoftware/Retreat-CoreSDK) — shared SDK
- [Retreat-Website](https://github.com/RetreatSoftware/Retreat-Website) — web platform
- [Retreat-Modules](https://github.com/RetreatSoftware/Retreat-Modules) — pluggable gameplay systems
- [Retreat-Engine-3D](https://github.com/RetreatSoftware/Retreat-Engine-3D) — 3D game engine
